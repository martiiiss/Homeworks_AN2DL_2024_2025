# Homeworks of "Artificial Neural Networks and Deep Learning" 2024/2025 @ POLIMI
## Homework 1 - Image Classification 
The project focuses on classifying 96×96 RGB blood cell images into 8 categories using deep learning. The main goal is to achieve high accuracy and generalization by leveraging transfer learning and fine-tuning.

## Homework 2 – Semantic Segmentation with U-Net
This project tackles multiclass image semantic segmentation of Mars terrain images using a U-Net neural network. The dataset consists of 2,615 training images and 10,022 test images (64×128 grayscale), with pixel-level masks for 5 terrain categories: Background, Soil, Bedrock, Sand, Big Rock.
